## 먼저 측정해야 하는 것

2단계 데이터 파이프라인 Flow 설계의 여러 항목이 같은 측정 하나에 걸려 있습니다.

**소스 간 중복률** — **방법이 09-20에 바뀌었다(`17`).** 파일 단위 `sha256` 교집합으로는 **영원히 0이 나온다.**

간이투자설명서가 DART에서는 별도 문서가 아니라 **투자설명서 PDF 안의 절**이기 때문이다. 금투협은 이를 별도 PDF로 주고, DART는 본문 안에 품고 있다. 서로 다른 파일 안의 같은 구간이라 파일 해시가 겹칠 수 없다.

→ **금투협 간이투자설명서 PDF ↔ DART 투자설명서 PDF 내 요약 구간**을 **절 단위로** 대조해야 한다. `scripts/dart_sections.py`가 절을 떼어 주므로 그 출력끼리 비교한다.

- 중복이 실재하면 → 소스 간 중복 제거 규칙 설계
- **CAS는 이 중복을 못 잡는다 (09-20).** CAS는 파일 해시 중복 제거인데 이 중복은 **서로 다른 파일 안의 같은 구간**이다. 「CAS 불채택」 근거로 쓸 수 있다
- 중복이 0이면 → 둘 다 불필요. `04` 3-1의 「문서 1건 = 펀드 1건」 논증도 그대로 성립

간이투자설명서가 양쪽에서 오는 것이 확인됐을 뿐(`12` 6절), 같은 원고라도 생성 경로가 다르면 해시가 다를 수 있어 실제 중복률은 미확인입니다.
