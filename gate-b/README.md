## 먼저 측정해야 하는 것

관문 B의 여러 항목이 같은 측정 하나에 걸려 있습니다.

**소스 간 중복률** — 금투협과 DART에서 같은 기간을 수집한 뒤 `raw_object.sha256`의 교집합을 센다.

- 중복이 실재하면 → 소스 간 중복 제거 규칙 설계 + CAS 재판단
- 중복이 0이면 → 둘 다 불필요. `04` 3-1의 「문서 1건 = 펀드 1건」 논증도 그대로 성립
