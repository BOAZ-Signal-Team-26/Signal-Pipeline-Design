## 질문 1. finlife(금융상품통합비교공시) 오픈 API에 펀드·ETF·ELS가 있는가

**확인됨.** finlife 오픈API 개요 페이지(`finlife.fss.or.kr/finlife/main/contents.do?menuNo=700029`)와 오픈API 소개 페이지(`menuNo=700051`)에 "금융상품 통합 비교공시 시스템에서는 아래의 8종류의 오픈 API검색 서비스들을 제공합니다"라는 문구와 함께 다음 8종이 명시되어 있다.

1. 금융회사개요 API
2. 정기예금상품 API
3. 적금상품 API
4. 연금저축상품 API
5. 주택담보대출상품 API
6. 전세자금대출상품 API
7. 개인신용대출상품 API
8. 개인사업자대출상품 API

**펀드·ETF·ELS(집합투자증권·파생결합증권) API는 이 8종에 포함되지 않는다.**

- 근거 URL: https://finlife.fss.or.kr/finlife/main/contents.do?menuNo=700029 , https://finlife.fss.or.kr/finlife/api/fncCoApi/list.do?menuNo=700051

**펀드 메뉴의 실체:** finlife 사이트 화면에는 "펀드" 메뉴가 존재하지만, 이 메뉴는 finlife 자체 API가 아니라 **금융투자협회 전자공시(dis.kofia.or.kr)로 리다이렉트**된다. 확인된 리다이렉트 대상:
`http://dis.kofia.or.kr/websquare/index.jsp?w2xPath=/wq/fundann/DISFundROPCmpAnn.xml`
→ 확인됨. 근거: https://finlife.fss.or.kr/finlife/main/main.do?menuNo=700000 (페이지 내 링크 텍스트를 WebFetch로 확인)

**`fin_prdt_cd` 필드:** 확인 불가. finlife API 개요/소개 페이지 자체에는 필드 레벨 명세가 실려 있지 않고(활용가이드 PDF·Swagger로 안내), WebFetch로 열어본 예제 응답에는 `fin_prdt_cd`가 아니라 `fin_co_no`(금융회사코드)만 확인됐다. `fin_prdt_cd`가 8종 API의 공통 응답 필드라는 것은 일반적으로 통용되는 지식이지만, 이번 조사에서 공식 페이지 원문으로는 직접 확인하지 못했다. **추정(미확인)**으로 표시한다.

## 질문 2. 펀드 단축코드 5자리 체계 교차 확인

### 2-1. 공공데이터포털 "펀드상품기본정보"(publicDataPk=15094792)의 `srtnCd`/`asoStdCd`

**부분 확인.** 상세 페이지(`https://www.data.go.kr/data/15094792/openapi.do`, 실제로는 `selectApiDataDetailView.do?publicDataPk=15094792`)에는 다음 개요만 노출된다.

> "펀드표준코드 정보로 금융투자회사가 운용하는 펀드의 명칭, 코드 등에 대한 기본정보 제공" / REST, JSON+XML / 일 1회 갱신

**출력 항목표(필드별 설명·자릿수)와 실제 응답 샘플은 이 웹페이지 화면에 텍스트로 노출되지 않고**, "오픈API 활용자가이드" 문서(docx) 다운로드와 Swagger 명세로만 제공된다. WebFetch가 페이지 HTML만 읽는 방식이라 첨부 문서 내부의 `srtnCd`/`asoStdCd` 설명·샘플 값은 이번 조사에서 인용하지 못했다. → **확인 불가**(활용가이드 docx 또는 Swagger를 직접 내려받아야 확인 가능).

### 2-2. E4675가 신한자산운용 펀드 코드인지

**확인 불가(정확 일치 미발견), 단 체계는 강하게 뒷받침됨.**

- 신한자산운용 공식 사이트(shinhanfund.com)는 펀드를 6자리 내부코드(`fundCd=274362` 등)로 조회하며, E4675 같은 협회식 코드는 화면에 노출되지 않았다.
- 대신 펀드 정보 사이트(FunETF, 펀드닥터)에서 "신한미국나스닥100인덱스증권자투자신탁(UH/H)"의 같은 펀드 계열에 대해 다음과 같은 12자리 코드를 확인했다.
  - `K55210E46710` (FunETF, https://www.funetf.co.kr/product/fund/view/K55210E46710)
  - `K55210E46694`, `K55210E46884` (펀드닥터, funddoctor.co.kr)
- 세 코드 모두 `K55210`(운용사코드 6자리) + `E467x`/`E468x`(단축코드 5자리, 영문1+숫자4 형식) + 말미 1자리(체크디지트)의 구조를 보인다. **E4675 자체와 정확히 일치하는 공개 페이지는 이번 조사에서 찾지 못했지만, 동일 펀드 계열의 다른 클래스들이 `K55210E4671…`, `K55210E4669…`, `K55210E4688…` 식으로 나타나 배경 정보(E4675, 신한자산운용)와 코드 구조가 정합적이다.**
- `K55210` = 신한자산운용의 운용사코드로 보인다(여러 신한 펀드 URL에서 반복 확인).
- 결론: **부분 확인.** E4675라는 정확한 값 자체는 공식 페이지에서 재현하지 못했으나, "5자리 단축코드 + 운용사코드 K55210(신한)"이라는 체계는 여러 3자(FunETF·펀드닥터) 페이지로 뒷받침된다. 3자 페이지는 1차 자료가 아니므로 2차 자료로 표시한다.

### 2-3. 금투협 12자리 펀드코드(운용사코드 6 + 단축코드 5 + 1)와 협회표준코드(KR5…/KRM…)가 별개 체계인가

**부분 확인.**

- 위 2-2의 사례들(`K55210E46710` 등)과 배경 정보의 `K55105B93082`(삼성달러표시단기채권)는 모두 `K + 운용사 5자리숫자 + 단축코드 5자리 + 체크디지트 1자리` = 12자리 구조로 일관되게 나타난다. 이는 여러 판매사·운용사·펀드정보 사이트(삼성자산운용 `samsungfund.com/fund/product/view.do?id=K55105EB5790`, ACE ETF `aceetf.co.kr/fund/K55101DB1182` 등)에서 반복 관찰되어 **준공식적으로 뒷받침**된다.
- 이 `K…` 코드와 한국예탁결제원 표준코드 체계인 `KR5…`(수익증권)/`KRM…` 등은 접두어부터 다른 별개 체계로 보이나, 이 둘의 관계를 명시적으로 설명하는 금투협·예탁결제원의 공식 해설 페이지는 이번 조사에서 열람하지 못했다. → **구조적 정황 증거는 확인, 공식 해설 문서 인용은 확인 불가.**
- **운용사코드 대응표:** 금투협(kofia.or.kr) 공지 게시판에 "운용사코드"라는 제목의 첨부파일(xlsx)이 존재하는 것은 검색으로 확인했고 다운로드도 성공했으나, 바이너리(xlsx) 내용을 이번 조사의 텍스트 추출 방식으로는 읽어내지 못해 실제 매핑 표(예: K55105=삼성자산운용)는 인용하지 못했다. 파일 자체의 존재와 URL만 확인됨.
  - URL: https://www.kofia.or.kr/brd/m_17/down.do?brd_id=www_notice&seq=1896&data_tp=A&file_seq=1
  - 배경 정보의 "K55105=삼성자산운용" 추정은 위 2-2·2-3에서 관찰된 삼성자산운용 URL 패턴(`samsungfund.com/fund/product/view.do?id=K55105…`)과도 일치하여 **정황상 확인됨**.

### 2-4. ETF는 펀드코드(5자리)와 거래소 종목코드(6자리)를 모두 갖는가

**부분 확인.**

- ETF도 집합투자기구이므로 위와 동일한 `K + 운용사코드 + 단축코드 + 체크디지트` 형태의 협회 펀드코드를 갖는 것으로 관찰된다(예: ACE ETF 페이지가 `K55101DB1182`로 접근됨).
- 동시에 거래소 매매를 위한 별도의 6자리 종목코드(예: KODEX 미국나스닥100 ETF = `367380`류, 검색 결과에 등장)도 갖는다.
- 둘을 공식적으로 잇는 단일 공개 API 페이지(금투협 ETF 공시 또는 KRX 정보데이터시스템의 대사표)는 이번 조사에서 직접 찾지 못했다. KRX 정보데이터시스템(data.krx.co.kr)에 ETF 관련 표준화공시·통계 메뉴가 있다는 것만 확인했고, 상세 대사 페이지까지는 확인하지 못했다. → **두 코드가 공존한다는 사실은 확인, 이를 공식적으로 매핑하는 단일 소스는 확인 불가.**

## 질문 3. ELS 식별 코드

**부분 확인.**

- ELS(주가연계증권)는 집합투자증권이 아니라 파생결합증권이므로, 위의 펀드코드(운용사코드+단축코드) 체계 밖에 있다는 전제 자체는 이번 조사와 상충하지 않는다(별도 코드 체계를 뒷받침하는 사례를 찾지 못했을 뿐, 펀드코드 체계에 속한다는 반증도 없음 — 구조상 타당한 추정).
- 공개적으로 ELS를 식별하는 방식으로 실제 확인된 것은 다음과 같다.
  - **발행사별 "제OOOO회" 회차 번호 + 상품명**: 예) "미래에셋증권 제29976회파생결합증권(주가연계증권)" (검색 결과에서 실제 PDF 파일명으로 확인, https://securities.miraeasset.com/public/hks4412/002/KR6MD0002NP4.pdf )
  - 이 URL의 파일명 자체가 `KR6MD0002NP4`, `KR6MD0002Y10` 형태의 **KR6…로 시작하는 12자리 표준코드**로 보인다. 다만 이 표준코드 체계를 공식적으로 해설하는 예탁결제원·금투협 문서는 이번 조사에서 별도로 열람하지 못했으며, 파일명에서 관찰된 정황 증거에 그친다.
- **DART 보고서 유형:** 금투협 법규정보시스템의 "파생결합증권·파생결합사채 신고서 작성 해설서"(https://law.kofia.or.kr/service/law/lawFullScreenContent.do?seq=286&historySeq=1605)에서 다음 보고서명을 확인했다.
  - 일괄신고서, **일괄신고추가서류**, 투자설명서, 간이투자설명서, 소액공모공시서류
  - 원문 인용: "투자판단시 일괄신고서, 일괄신고추가서류, 투자설명서 및 간이투자설명서를 반드시 참고 하시기 바랍니다."
  - 즉 ELS는 개별 증권신고서가 아니라 **"일괄신고서 + 일괄신고추가서류"** 방식으로 DART에 공시되는 경우가 일반적임을 준공식 문서로 확인했다.
  - 다만 이 해설서 자체는 작성 지침 문서로, ELS 개별 종목의 표준코드·식별번호 체계까지는 규정하지 않는다.

## 결론

1. **finlife에 펀드·ETF·ELS가 있는가 — 없다.** finlife 오픈API는 정기예금·적금·연금저축·주택담보대출·전세자금대출·개인신용대출·개인사업자대출·금융회사개요 8종뿐이며, 펀드는 화면상 메뉴만 있고 실제로는 금투협 전자공시(dis.kofia.or.kr)로 연결되고, ETF·ELS는 finlife 어디에도 없다.
2. **단축코드 5자리가 DART와 펀드상품기본정보를 잇는 키로 쓸 수 있는가 — 구조적으로는 그렇다고 보이나 이번 조사만으로 전면 확정하기엔 이르다.** `K+운용사코드6자리+단축코드5자리+체크디지트1자리`(예: K55210E4671…) 구조는 여러 운용사·펀드정보 사이트에서 정합적으로 관찰되어 협회 공식 코드 체계로 보이지만, 공공데이터포털 "펀드상품기본정보" API의 `srtnCd`/`asoStdCd` 필드 명세를 원문(활용가이드/Swagger)으로 직접 확인하지 못했고, DART 표지의 E4675 자체도 정확히 재현하지 못했다. 활용가이드 docx나 Swagger 명세를 별도로 받아 필드 정의를 대조하는 추가 확인이 필요하다.
3. **ELS 식별 키 후보는 무엇인가 — 발행사별 회차 번호("제OOOO회")와 KR6…형 표준코드, 그리고 DART상 "일괄신고서/일괄신고추가서류" 문서 단위**가 사실상의 식별 단위로 관찰된다. 다만 KR6… 코드의 공식 해설 문서는 확보하지 못해 이 부분은 정황 증거 수준이다.

## 보충 (대현, 09-14): 운용사코드 xlsx 직접 해석

위 2-3에서 내용을 읽지 못했다고 한 금투협 첨부 xlsx(`운용사코드` 시트, 536행)를 파이썬으로 풀어 `ref_kofia_mgmt_codes.csv`로 저장했다. 열은 운용사 코드, 운용사명, 단축명, 변경전 운용사명이다.

- 운용사 코드는 **3자리 영숫자**다(105, 210, 301, 4C4, 3U3 …). 「운용사코드 6자리」는 부정확하며, 12자리 펀드코드는 `K55` + 운용사 3 + 단축코드 5 + 검증 1 로 분해된다.
- 대조: K55**105**B93082 → 105 삼성자산운용. K55**210**E46710 → 210 신한자산운용(변경전 신한비엔피파리바자산운용). K55**301** → 301 미래에셋자산운용. 팀의 09-05 주장 「K55301은 미래에셋」은 맞았고, web-verify B1이 「근거를 찾지 못했다」고 한 부분은 이 표로 해소된다.
- 출처: https://www.kofia.or.kr/brd/m_17/down.do?brd_id=www_notice&seq=1896&data_tp=A&file_seq=1 (금투협 공지 첨부, 펀드 평가 제출 양식의 부속 시트). 공식 마스터가 아니라 양식 첨부이므로 갱신 주기는 미확인.
